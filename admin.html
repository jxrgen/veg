Importer ny markplan

Vælg en CSV-fil i det rigtige format for at opdatere markplanen.

Forhåndsvisning

Bed Top afgrøde Status Midt afgrøde Status Bund afgrøde Status

Filformat

Semikolon-separeret .csv-fil med 7 kolonner pr. linje. Første linje er header og ignoreres.

Bed Top Midt Bund
Afgrøde Status Afgrøde Status Afgrøde Status
38 Grønkål X X X
15 Majs X Løg X Spidskål -
1 X X Hestebønner X

Samme rækker som CSV-fil

;Top;;Midt;;Bund;
38;Grønkål;X;;X;;X
15;Majs;X;Løg;X;Spidskål;-
1;;X;;X;Hestebønner;X
→ Separator: ; (semikolon)
→ Maks 40 rækker (bede)
→ X = ikke frigivet  ·  - = klar til høst
→ Tomt afgrødefelt = tomt bed i den sektion
→ Første linje er header og ignoreres. Lugegruppetilknytning bevares ved import.
