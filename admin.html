Filformat

Semikolon-separeret .csv-fil med 7 kolonner pr. linje. Første linje er header og ignoreres.

Bed Top Midt Bund
Afgrøde Status Afgrøde Status Afgrøde Status
38 Grønkål X X X
15 Majs X Løg X Spidskål -
1 X X Hestebønner X

Samme rækker som CSV-fil

;Top;;Midt;;Bund;
38;Grønkål;X;;X;;X
15;Majs;X;Løg;X;Spidskål;-
1;;X;;X;Hestebønner;X
→ Separator: ; (semikolon)
→ Maks 40 rækker (bede)
→ X = ikke frigivet  ·  - = klar til høst
→ Tomt afgrødefelt = tomt bed i den sektion
→ Første linje er header og ignoreres. Lugegruppetilknytning bevares ved import.

Filformat — lugegrupper

Semikolon-separeret .csv-fil med gruppeoverskrifter og medlemsrækker.

Gruppe 1
Navn;Adresse;Email;Mobil;BG
Anders Jensen;Havevej 3;anders@example.dk;20304050;12
Birthe Nielsen;Marksti 7;Birthe Nielsen <birthe@example.dk>;30405060;5
Gruppe 2
Navn;Adresse;Email;Mobil;BG
Carl Holm;Engvej 2;carl@example.dk;40506070;8
→ Separator: ; (semikolon)
→ Gruppelinjer starter med Gruppe N
→ Kolonner: Navn · Adresse · Email · Mobil · BG
→ Email kan stå som Navn <email@…>

Admin vejledning

Markplan for Grøntsagsordningen i AiH

1 Login

  • Tryk 5 gange på overskriften i markplan-appen for at komme til admin-login
  • Skriv admin-koden og klik Log ind
  • Klik Log ud øverst til højre for at vende tilbage til markplan-oversigten
  • Sessionen bevares ikke ved genindlæsning — du skal logge ind igen

2 Faneblad: Lugegrupper & Medlemmer

  • Viser alle medlemmer fordelt på deres lugegrupper
  • Brug Filter-dropdownen øverst til at vise kun én gruppe
  • Sorter ved at klikke på kolonneoverskrifter: Gruppe, Fornavn, Efternavn, Adresse, Telefon, Email, BG — klik igen for omvendt rækkefølge

3 Faneblad: Afgrøder & Høst

  • Viser alle afgrøder i to sektioner: Frigivet og Låst
  • Klik på en afgrøde (eller på toggle-kontakten) for at skifte status
  • Frigivet = grønt check i bruger-appen  ·  Låst = rød hængelås
  • Ændringen sker øjeblikkeligt og opdaterer alle bede med den pågældende afgrøde

4 Faneblad: Importer

  • Importer ny markplan — erstatter afgrødeplan og høststatus (lugegruppetilknytning bevares)
  • Importer lugegrupper — erstatter alle eksisterende medlemmer med data fra filen
  • Begge funktioner viser en forhåndsvisning og beder om bekræftelse inden import

CSV-format — markplan

;Top;;Midt;;Bund;          ← header (ignoreres)
38;Grønkål;X;;X;;X
15;Majs;X;Løg;X;Spidskål;-
1;;X;;X;Hestebønner;X
→Separator: ;
→7 kolonner: Bed;TopAfgrøde;TopStatus;MidtAfgrøde;MidtStatus;BundAfgrøde;BundStatus
→X = ikke klar  ·  - = klar til høst
→Maks 40 rækker, første linje er header og ignoreres
